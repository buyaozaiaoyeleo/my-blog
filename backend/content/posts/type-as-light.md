字体和灯一样，装得一样亮，房间就没有角落。这艘船上至少有三盏不同的灯。

中文标题用衬线。衬线在暗背景上把笔画收住，标题看起来像印出来的，而不是渲染出来的。正文用无衬线，行距松开，长时间读的是它，不是标题。界面上的小标签、导航、时间，用另一套更窄的无衬线，让它们像仪表上的刻度，而不是另一篇文章。

英文和数字再分开。LOG、章节编号、年份，用一张显示用的衬线。它们数量少，可以比正文更有性格。如果编号也用正文那套字，章节的拍点就会消失。

不要用第四盏灯。手写体、像素体、过重的黑体会在夜里抢句子。偶尔在封面里出现可以，一进正文就该下班。

字号也按灯来分。船名最大，亮得像舱外的名字。章节编号次之。正文是阅读用的常亮，不追求戏剧。注释和时间是微光，在，但不叫人。

有一段我反复回来看的写法：

```css
:root {
  --amber: #e7a23a;
}
```

高光色是一枚变量，字体的分工也应该一样清楚。哪一套负责标题，哪一套负责刻度，写在一处，全站就不用临时决定。

灯不要装得一样亮。字也不要长得一样。
